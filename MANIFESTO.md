# Dev Doodles Manifesto

This is a stalker's notebook from the Zone of the Linux kernel.

I do not map the Zone.
I only record the paths I actually walked and the anomalies worth revisiting.

## The Stalker's Code

- **A small experiment beats a large plan.**
  A 50-line program can illuminate a thousand pages of documentation.

- **Man pages are the asylum orderlies.**
  Experiments for their own sake should be avoided.
  If something is clear from the man pages, so be it.

- **Reality wins over bold assumptions.**
  If an observation contradicts my mental model, I take a note and move on.

- **Notes are the first class citizens.**
  These notes may be incomplete, naive, or wrong.
  They only need to be useful to my future self.

- **No pain, only gain.**
  Understanding is more valuable than optimization.

- **Automation is a trap.**
  Commenting lines of code is enough. No additional tooling is needed.

- **Bugs are part of the landscape.**
  I fix them only when I notice them. Some might stay here forever, buried under the dust.

- **Finished, not expanded.**
  The repository grows by completing experiments, not by scaling them.

- **The purpose is not to become a Linux guru.**
  The purpose is to remain a humble curious engineer.

Welcome to the Zone, stalker.
